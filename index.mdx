Spin is an open source framework and CLI for building, distributing, and running fast, secure serverless applications powered by WebAssembly. It leverages the WebAssembly component model and the Wasmtime runtime to give you instant startup times, strong sandboxing, and multi-language support — all from a single `spin` command.

## Getting started

<Steps>
  <Step title="Install Spin">
    Download and install the Spin CLI with a single command:
    ```bash
    curl -fsSL https://spinframework.dev/downloads/install.sh | bash
    sudo mv ./spin /usr/local/bin/spin
    ```
  </Step>
  <Step title="Create a new application">
    Scaffold a new Spin app from a template:
    ```bash
    spin new --accept-defaults -t http-rust hello-spin
    cd hello-spin
    ```
  </Step>
  <Step title="Build and run">
    Compile your component to WebAssembly and start the local server:
    ```bash
    spin build
    spin up
    ```
  </Step>
  <Step title="Test it">
    Send a request to your running application:
    ```bash
    curl http://127.0.0.1:3000
    # Hello World!
    ```
  </Step>
</Steps>
