This quickstart walks you through creating a new Spin application, compiling it to WebAssembly, running it locally, and sending your first request. You will use the `http-rust` template, which scaffolds a minimal HTTP handler in Rust that returns `Hello World!`.

<Steps>

<Step title="Install Spin">

If you have not installed Spin yet, run the install script and move the binary to your `PATH`:

```bash
curl -fsSL https://spinframework.dev/downloads/install.sh | bash
sudo mv ./spin /usr/local/bin/spin
```

You also need the `wasm32-wasip2` Rust target to compile Rust components to WebAssembly:

```bash
rustup target add wasm32-wasip2
```

See the [install page](/install) for full system requirements and alternative installation methods.

</Step>

<Step title="Create a new application">

Use `spin new` with the `http-rust` template to scaffold a new application called `hello-rust`:

```bash
spin new --accept-defaults -t http-rust hello-rust
```

The `--accept-defaults` flag skips interactive prompts and uses the template defaults. Spin creates a `hello-rust/` directory with the following structure:

```
hello-rust/
├── spin.toml       # Application manifest
├── Cargo.toml      # Rust package definition
└── src/
    └── lib.rs      # HTTP handler
```

**`spin.toml`** — the application manifest that declares your component, its trigger route, its Wasm source path, and the build command:

```toml spin.toml
#:schema https://schemas.spinframework.dev/spin/manifest-v2/latest.json

spin_manifest_version = 2

[application]
name = "hello-rust"
version = "0.1.0"
authors = ["Your Name <you@example.com>"]
description = ""

[[trigger.http]]
route = "/..."
component = "hello-rust"

[component.hello-rust]
source = "target/wasm32-wasip2/release/hello_rust.wasm"
allowed_outbound_hosts = []
[component.hello-rust.build]
command = "cargo build --target wasm32-wasip2 --release"
watch = ["src/**/*.rs", "Cargo.toml"]
```

**`src/lib.rs`** — the HTTP handler generated by the template. It logs the request URL and returns a plain-text `Hello World!` response:

```rust src/lib.rs
use spin_sdk::http::{IntoResponse, Request, Response};
use spin_sdk::http_service;

/// A simple Spin HTTP component.
#[http_service]
async fn handle_hello_rust(req: Request) -> anyhow::Result<impl IntoResponse> {
    println!("Handling request to {:?}", req.headers().get("spin-full-url"));
    Ok(Response::builder()
        .status(200)
        .header("content-type", "text/plain")
        .body("Hello World!".to_string()))
}
```

</Step>

<Step title="Build the application">

Change into the project directory and run `spin build`. Spin reads the `build` command from `spin.toml` and compiles each component to WebAssembly:

```bash
cd hello-rust
spin build
```

You should see output like this:

```
Executing the build command for component hello-rust: cargo build --target wasm32-wasip2 --release
    Finished release [optimized] target(s) in 0.03s
Successfully ran the build command for the Spin components.
```

<Tip>
  Run `spin build --up` to build and start the application in a single command.
</Tip>

</Step>

<Step title="Run the application">

Start the Spin runtime and serve your application locally:

```bash
spin up
```

Spin prints the listening address and the routes it has registered:

```
Logging component stdio to ".spin/logs/"

Serving http://127.0.0.1:3000
Available Routes:
  hello-rust: http://127.0.0.1:3000 (wildcard)
```

</Step>

<Step title="Test it">

Open a new terminal and send an HTTP request to your running application:

```bash
curl -i http://127.0.0.1:3000
```

You should receive a `200 OK` response with the `Hello World!` body:

```
HTTP/1.1 200 OK
content-type: text/plain
transfer-encoding: chunked
date: Sun, 02 Mar 2025 20:09:11 GMT

Hello World!
```

</Step>

</Steps>

## Explore other templates

Spin ships with templates for multiple languages and trigger types. Run `spin templates list` to see everything installed, or use any of the templates below with `spin new -t <template-name> <app-name>`:

<CodeGroup>

```bash Rust (HTTP)
spin new --accept-defaults -t http-rust hello-rust
```

```bash Go (HTTP)
spin new --accept-defaults -t http-go hello-go
```

```bash Rust (Redis)
spin new --accept-defaults -t redis-rust hello-redis
```

```bash Go (Redis)
spin new --accept-defaults -t redis-go hello-redis
```

```bash Static file server
spin new --accept-defaults -t static-fileserver my-site
```

</CodeGroup>

| Template | Language | Trigger | Description |
|---|---|---|---|
| `http-rust` | Rust | HTTP | HTTP request handler using Rust |
| `http-go` | Go (TinyGo) | HTTP | HTTP request handler using Go |
| `http-c` | C | HTTP | HTTP request handler using C |
| `http-grain` | Grain | HTTP | HTTP request handler using Grain |
| `http-php` | PHP | HTTP | HTTP request handler using PHP |
| `http-zig` | Zig | HTTP | HTTP request handler using Zig |
| `redis-rust` | Rust | Redis | Redis pub/sub message handler using Rust |
| `redis-go` | Go (TinyGo) | Redis | Redis pub/sub message handler using Go |
| `static-fileserver` | — | HTTP | Serve static files from a directory |
