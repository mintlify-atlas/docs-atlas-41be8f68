Spin is an open source framework for building and running fast, secure, and composable cloud microservices with WebAssembly. It aims to be the easiest way to get started with WebAssembly microservices, and takes advantage of the latest developments in the [WebAssembly component model](https://github.com/WebAssembly/component-model) and the [Wasmtime](https://wasmtime.dev/) runtime.

## How Spin works

A Spin application is made up of one or more **components** — WebAssembly modules that handle events from a **trigger**. Spin loads your components, wires them to their triggers, and manages the runtime lifecycle for you.

- **Triggers** define what event starts a component. Spin ships with HTTP and Redis triggers built in.
- **Components** contain your application logic compiled to WebAssembly. They start instantly, run in a sandboxed environment, and stop when the request is done.
- **Capabilities** (called factors internally) are opt-in APIs your component can use: outbound HTTP, key-value storage, SQLite, PostgreSQL, MySQL, Redis pub/sub, and serverless AI inference.

The application manifest (`spin.toml`) declares every component, its trigger route or channel, its Wasm source file, and the build command Spin uses to compile it.

## Language support

WebAssembly is language-agnostic. You write your component in a supported source language, compile it to Wasm, and Spin runs it. The Spin framework team maintains SDKs for four languages:

| Language | SDK | Notes |
|---|---|---|
| Rust | [crates.io/crates/spin-sdk](https://crates.io/crates/spin-sdk) | Full feature coverage; primary SDK |
| JavaScript & TypeScript | [github.com/spinframework/spin-js-sdk](https://github.com/spinframework/spin-js-sdk) | Supports both HTTP and Redis triggers |
| Python | [github.com/spinframework/spin-python-sdk](https://github.com/spinframework/spin-python-sdk) | Supports HTTP, Redis, and outbound HTTP |
| Go | [pkg.go.dev/github.com/fermyon/spin/sdk/go/v2](https://pkg.go.dev/github.com/fermyon/spin/sdk/go/v2) | Uses TinyGo to target `wasip1` |

Community-maintained SDKs also exist for Zig and Moonbit.

<Note>
  The Spin framework team supports the JavaScript, Rust, Go, and Python SDKs. Other language integrations are supported by their authors.
</Note>
